# Change log (everything built so far)

1. **Base builder** – dynamic columns (Product Image, Product Name, MRP, Net Weight, Selling Price), editable rows, image upload, live preview, header/footer, templates, save/load/import/export, PNG/PDF/PPT/print.
2. **One-row default + editor UI refresh** – New Pamphlet starts with one blank row; two-tone blue/white editor.
3. **Download Output dialog** – choose format, page size, resolution, trim; light/dark theme toggle; redesigned floating windows.
4. **Editing upgrades** – multi-line Product Name (Enter = new line), borderless larger product images (auto-trim, auto-fit column), full-page preview with open/close editor, sort rows, fonts with size/weight options.
5. **Output upgrades** – JPEG added, draggable trim box, "compress layout" resize, remove empty space, curved corners, 54+ Google fonts (soft, sharp, fun, Tamil/Hindi friendly).
6. **UI features** – cursor trail, welcome banner with stats, section tabs, search, bulk image upload, undo/redo, ready-made templates, help, quick-action button, saved badge, style presets, themed scrollbars.
7. **Keyboard + mobile** – Enter moves to next row (and runs the primary button in pop-ups), mobile layout with bottom bar, card-style product list, hamburger menu.
8. **Horizontal pamphlet** – second layout (A5 landscape) with banner header, big product images, big name/price, heading row, footer strip; layout switch per pamphlet.
9. **Pamphlet tabs** – many pamphlets open in parallel (own data, settings, layout and undo history); rename / duplicate / close; tab name becomes the header title; SVG icons for vertical and horizontal.
10. **Image crop editor** – crop from top, bottom, left and right (drag handles or sliders), crop shapes, rotate/flip, view zoom, re-edit any applied image.
11. **Spreadsheet-style editing** – arrow keys move between cells like Excel / Google Sheets (Ctrl+Arrow jumps to the edge, Home/End, PageUp/PageDown, F2 to edit), Ctrl+D fill down, paste cells copied from Excel/Sheets, drag rows to reorder, insert row below, active-cell status bar, row highlight.
12. **Sharper downloads** – pages are rendered at 2x and smoothly scaled down, so compressed / smaller exports stay crisp and look like the full-size version.
13. **Mobile + app extras** – floating "+ Row" button, pinch-to-zoom preview, fullscreen preview, installable app (manifest, offline cache, icons).
